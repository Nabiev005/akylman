# Akylman.kg

**«Санарип аймак» багыты** — региондук мектептер жана окуу борборлору үчүн SaaS платформасы (LMS & School Management).

## Проблема

Айыл жергелериндеги жана региондордогу мектептерде электрондук журналдар, окуучулардын жетишүүсүн көзөмөлдөө,
ата-энелер менен байланыш жана отчеттуулук процесси толук санариптештирилген эмес же ыңгайсыз.

## Чечим

Мектептерге жана билим берүү мекемелерине арналган веб жана мобилдик платформа. Окуучулардын баалары, катышуусу,
үй тапшырмалары, мугалимдердин отчеттору жана ата-энелердин көзөмөлү бир жерде биригет. Мугалим журналга бир жолу
киргизген маалымат ата-энеге, директорго жана райондук билим берүү бөлүмүнө автоматтык түрдө жетет.

## Ролдор жана модулдар

| Роль | Мүмкүнчүлүктөр |
|---|---|
| **Мугалим** | Электрондук журнал (баа коюу), катышууну белгилөө, үй тапшырма берүү жана аткарылышын көрүү, журналдан автоматтык түзүлгөн айлык отчет, билдирүүлөр |
| **Ата-эне** | Баланын баалары реалдуу убакытта, катышуу календары, үй тапшырмалар (аткарылды деп белгилөө), сабак жадыбалы, мугалимге түз жазуу, бир нече баланы алмаштыруу |
| **Мектеп директору** | Мектептин аналитикасы, эрте эскертүү (артта калган / көп калтырган окуучулар), мугалимдердин активдүүлүгү, отчетторду бекитүү, районго айлык отчет жөнөтүү, Excel (CSV) экспорт |
| **Райондук билим бөлүмү** | Райондун бардык мектептери бир панелде, мектептердин рейтинги, санариптештирүү абалы, келген отчеттор, Excel экспорт |

## Ишке киргизүү

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн билд → dist/
```

Демо режимде сыр сөз талап кылынбайт: башкы беттен **«Демону ачуу»** → ролду тандап кириңиз.
Кеңеш: мугалим катары журналга баа коюп, андан кийин ата-эне (Адылбекова Нургүл) катары кирип көрүңүз — баа дароо көрүнөт.

Демо-маалыматтар браузердин `localStorage`'ында сакталат. Каптал менюдагы **«Демону кайра баштоо»** баштапкы абалга кайтарат.

## Технологиялар

React 19 · TypeScript · Vite · styled-components · lucide-react. Мобилдик ылайыктуу интерфейс, PWA манифести (телефондун үй экранына орнотулат).

## Долбоордун түзүлүшү

```
src/
  App.tsx                  — лендинг → кирүү → ролго жараша панель
  types.ts                 — маалымат моделдери
  data/mockData.ts         — мектеп, класстар, мугалимдер, окуучулар, демо-маалымат генератору
  store/                   — бардык ролдор колдонгон жалпы абал (localStorage менен)
  utils/                   — даталар, статистика, аналитика, билдирүүлөр
  components/              — UI-кит, макет (sidebar / мобилдик меню), логотип
  pages/
    Landing.tsx            — проблема, чечим, мүмкүнчүлүктөр, масштабдоо, тарифтер
    Login.tsx              — демо-кирүү (4 роль)
    TeacherDashboard.tsx
    ParentDashboard.tsx
    DirectorDashboard.tsx
    DistrictDashboard.tsx
    shared/MessagesPage.tsx
```

## Кийинки кадамдар

- Backend (API + маалымат базасы), SMS-код аркылуу кирүү
- Оффлайн режим (Service Worker) жана SMS-билдирүүлөр ата-энелерге
- Чейректик / жылдык баалар, сабак жадыбалын түзүү модулу
- Билим берүү министрлигинин маалымат системалары менен интеграция
- Окуу борборлору үчүн LMS модулу (курстар, онлайн тапшырмалар)
